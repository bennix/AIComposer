AI 强化了什么

What the AI layer adds

生图

Generate

按提示词新建图层：静物、纹理、海报、变体。

Create a new layer from a prompt: still life, texture, poster, or variation.

选区改图

Edit a selection

填充、去物体、去字迹，或把选中的图形文字识别成可编辑文字。原图、选区蒙版和提示词一并送给模型，结果写回当前图层。

Fill, remove objects, clear handwriting, or convert selected graphic type into live editable text. The photo, selection mask, and prompt go out together; the result writes back to the current layer.

扩图与换天空

Expand and sky

生成式扩图、替换天空、风格重绘。会处理接缝、黑边和画幅，避免图被越改越小。

Generative expand, sky replacement, and restyle. Seams, letterboxing, and shrinking frames are handled in the pipeline.

仍然是一台完整的图像编辑器

Still a full image editor

图层、蒙版与 PSD

Layers, masks, and PSD

文件夹、混合模式、不透明度、图层蒙版、剪贴蒙版、调整图层。可导入 Photoshop PSD（8-bit RGB）以及相机 RAW。

Folders, blend modes, opacity, layer masks, clipping masks, and adjustment layers. Import Photoshop PSD (8-bit RGB) and camera RAW.

修饰与变换

Retouch and transform

画笔、修复、仿制、套索、魔棒、扭曲、裁剪，以及色阶/曲线/色相饱和度。

Brush, healing, clone, lasso, magic wand, distort, crop, plus Levels, Curves, and Hue/Saturation.

熟悉的原生界面

A familiar native editor

编辑器支持简体中文、英文、日文、繁体中文、韩文。新版创作引导采用中文界面，风格数据可按系统语言切换。

The editor supports Simplified Chinese, English, Japanese, Traditional Chinese, and Korean. The new creative guide uses a Chinese interface; style metadata follows the system language.

ZenMux 接入

ZenMux inside the app

在设置里填入 ZenMux API Key（加密保存在本机）。生图可选 GPT Image、Qwen Image、Gemini Image；另可填写多模态模型（默认 google/gemini-3.8-flash）用于识别图形文字。没有 Key 时可用邀请链接注册。密钥不会进仓库。

Paste a ZenMux API key in Settings. It is encrypted on this Mac. Image models: GPT Image, Qwen Image, Gemini Image. A separate multimodal model name (default google/gemini-3.8-flash) is used to read graphic type. Invite links work when you do not have a key yet. Keys never enter the repository.
