NEW / References & posing

从图像参考，到人物姿态。

From image references to character poses.

05—06

最多 5 张参考图

Up to five references

拖入、粘贴或选择图片，以缩略图管理。每张图可作为灵感、人物脸、服装、姿态或场景参考；删除后提示词自动更新“参考图 1、2、3…”，并按当前顺序发送。

Drop, paste, or choose images and manage them as thumbnails. Assign each as inspiration, identity, clothing, pose, or scene. Removing an image updates the numbered prompt references and sends the remaining images in order.

多人造型与身份保持

Multiple people, distinct identities

为 1–5 位人物分别指定脸部、服装与姿态参考，也可叠加换衣和换场景。换脸时提示模型严格保留参考脸的生物特征，不混合不同人物身份。

Direct one to five people with separate face, clothing, and pose references. Combine outfit and scene changes. Face edits instruct the model to preserve the reference identity’s defining facial features without blending people together.

IK 人偶姿态编辑

IK mannequin posing

用可操控的人偶摆姿势，支持反向运动学（IK）、关节限位、多人独立控制、镜像与自动落地。导出的姿态图作为单独的姿态引导附件，不会和普通参考图编号混淆。

Pose an interactive mannequin with inverse kinematics (IK), joint limits, per-person controls, mirroring, and automatic grounding. The exported pose guide is sent as a separate attachment, distinct from numbered image references.

5,424 / 24内置图库样图 / 归纳画面配方Bundled gallery previews / visual recipes

从 OpenNana 可公开访问的案例样图归纳画面构成、色彩、光线、材质与构图，再融合进创作引导。付费案例不复制原始提示词；根据可见图像提炼视觉特征，让参考灵感服务于你的主题。

Visual traits such as composition, color, lighting, and material are distilled from publicly viewable OpenNana sample images and folded into the creative guide. Paid prompt text is not copied; visible images inform visual direction for your own subject.

AI 强化了什么

What the AI layer adds

生图

Generate

按提示词新建图层：静物、纹理、海报、变体。

Create a new layer from a prompt: still life, texture, poster, or variation.

选区改图

Edit a selection

填充、去物体、去字迹，或把选中的图形文字识别成可编辑文字。原图、选区蒙版和提示词一并送给模型，结果写回当前图层。

Fill, remove objects, clear handwriting, or convert selected graphic type into live editable text. The photo, selection mask, and prompt go out together; the result writes back to the current layer.

扩图与换天空

Expand and sky

生成式扩图、替换天空、风格重绘。会处理接缝、黑边和画幅，避免图被越改越小。

Generative expand, sky replacement, and restyle. Seams, letterboxing, and shrinking frames are handled in the pipeline.

Layers, masks, and PSD

Folders, blend modes, opacity, layer masks, clipping masks, and adjustment layers. Import Photoshop PSD (8-bit RGB) and camera RAW.

ZenMux 接入

ZenMux inside the app

在设置里填入 ZenMux API Key（加密保存在本机）。图像模型支持自定义添加和删除，内置 GPT Image、Qwen Image、Gemini Image，可选择 OpenAI Images 或 Google Vertex 接口；另可填写多模态模型（默认 google/gemini-3.8-flash）用于识别图形文字。没有 Key 时可用邀请链接注册。密钥不会进仓库。

Paste a ZenMux API key in Settings. It is encrypted on this Mac. Add or delete image models, including built-in GPT Image, Qwen Image and Gemini Image. Custom IDs support OpenAI Images and Google Vertex routing. A separate multimodal model name (default google/gemini-3.8-flash) is used to read graphic type. Invite links work when you do not have a key yet. Keys never enter the repository.
