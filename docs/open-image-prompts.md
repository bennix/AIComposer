# Open Image Prompts 原生整合

入口：AI 面板 → 引导式创作 → 探索风格 → **Open Image Prompts · 双 Skill**。

## 一条创作流

1. 在创作意图中填写主体与用途，仍可使用人物姿态和已有参考图。
2. **Taste · 视觉方向**：比较风格卡，查看适用/不适用场景、视觉语法、边界、反模式和原始模板。实验性卡默认隐藏，可主动展开。选择主卡后查看其真实案例。
3. **Prompts · 真实参考**：按自己的意图搜索，查看作者、稳定 ID、原始来源、真实图片和未修改的原始文本。中文译文独立显示。帖子说明不保证都是可执行提示词。
4. 可选最多三条文字参考；只有明确点击「将当前图片加入生成参考」的图片才会进入模型输入，沿用编辑器最多五张参考图的限制。
5. 在画面语言中编辑构图、材质、光线、配色、氛围、比例、必须保留和避免项；`creative_spec` 可展开查看。
6. 可直接使用创作说明，不需要 API Key。也可明确点击「AI 整理中英文新提示词」，通过现有 ZenMux 多模态模型生成分开的英文/中文新提示词与引用理由。该调用会发送所选原文、创作说明及已加入的 OIP 图片，原文不会被覆盖。
7. 选择输出语言，进入最终提示词确认，再回到原有 AI 生图/改图与图层流程。

## 全量数据与出处

上游：[NanmiCoder/open-image-prompts](https://github.com/NanmiCoder/open-image-prompts)

固定快照：`6862f01c447c48f215981df57b2243e5a8ebb70a`，数据版本 `2026-11-12-0607`，分类版本 `oip-visual-v2`。

- 39 张完整风格卡，保留上游模板和每张卡的 GitHub 来源链接。
- 23,196 条原始帖子/提示词，保留作者、来源、原始文本与中英文译文。
- 38,519 张图片的原始 URL、本地相对路径与配对 ID。
- 185 个分类标签；568,909 条归并后的提示词/图片证据关联。
- 内置本地只读 SQLite 索引压缩资源约 63.5 MiB，首次使用在应用支持目录展开。客户端无需 Python、Node 或额外服务器，也不需要下载索引。
- 全部 38,519 张 OIP 参考图与现有 5,424 张 OpenNana 样图均在应用资源包中，不进行图片网络请求，不回退到在线源地址。固定上游图片包合计 6,151,164,702 字节；构建端还会补齐索引中有记录但图片包未提供的文件；X 地址拒绝读取时使用上游代码注明的官方自托管媒体镜像。

### 上游引用缺口

固定快照中有 12 张卡的真实参考列表为空；另有三个引用 ID 不在当前数据集中：
`2072542433213391291`、`2073830761359372552`、`2047968525243826505`。
原始卡不被删改，界面显示缺口，允许另行检索。不会为这些引用补造图片或作者。

### 原生检索适配

本应用采用原生 Swift/SQLite 实现，复用上游双语别名、概念约束和 v2 分类数据，**不声称与上游 Python 排序器逐条等价**。

- 显式标签、主体关键词与禁止项保留为约束；未知字词不会被默默丢弃。
- 主结果表示标签/原文/译文匹配，不表示图像质量已经由模型评审。
- 相关结果最多缺少一项视觉风格、光线、配色、氛围或构图条件，明确显示缺失项；不放宽主体、用途、场景、字词和禁止项，并要求匹配标签具有图片证据。
- 风格卡自带案例与意图搜索结果分开，前者只证明视觉语法，不保证主体匹配。
- 无匹配时显示资料库缺口，不退回通用网页图片搜索或虚构来源。

### 全部内置的图片

`OpenImagePromptsImages.bundle` 与 `OpenNanaImages.bundle` 作为完整资源目录复制进 `.app`，保留原始配对路径。
客户端只读包内文件：检索、风格卡、原文、译文、作者信息与图片浏览均可离线使用。来源链接仅供用户主动打开核查，不参与预览。
AI 整理及生图仍是主动调用的现有联网模型功能，不属于离线图片检索。

每个资源包包含 `Inventory.json`，记录全部相对路径、长度与 SHA-256。发布脚本在打包前检查完整性，缺少任何一张图即终止打包。图片文件共 7,175,486,100 字节（约 7.18GB），不写入 Git 历史，但会完整进入应用和安装包。

## 维护与复现

从上游官方 release 拉取并校验数据库，再运行导入器：

```sh
python3 /path/to/open-image-prompts/scripts/fetch_dataset.py
python3 scripts/import_open_image_prompts.py /path/to/open-image-prompts
python3 scripts/bundle_creative_images.py --checkout /path/to/open-image-prompts
python3 scripts/verify_creative_images.py --hashes
```

导入器检查上游数据库 SHA-256 和完整行数，生成 `Archive.oip`、39 张卡、意图规则、分类、图片包 manifest 和来源清单。
SQLite 压缩只发生在构建端，使用系统 Swift/Foundation 的 LZFSE；客户端使用系统框架展开读取。
